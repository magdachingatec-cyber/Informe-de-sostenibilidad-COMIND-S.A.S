# Informe-de-sostenibilidad-COMIND-S.A.S
Bienvenidos a nuestro informe de sostenibilidad 2021, de la matriz Minerali Industriali y la Filial COMIND S.A.S

## Portafolio de maquillaje 3D (Aurora Glam Studio)
Página web de ejemplo en `maquillaje-3d/index.html`: portafolio de maquilladora con productos de maquillaje en 3D (Three.js), galería con filtros, servicios y precios en COP, testimonios y formulario de reservas que arma un mensaje de WhatsApp.

Para verla, abre `maquillaje-3d/index.html` en el navegador (necesita internet para cargar Three.js y las fuentes). Los nombres, precios y datos de contacto son de ejemplo y se editan directamente en el archivo.
